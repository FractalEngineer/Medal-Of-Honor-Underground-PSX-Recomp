## Resume after a fresh save

Run these steps in order. Do not reuse the current profile data.

1. Boot the normal launcher and create fresh savestates in the heavy outdoor and
   second-scene locations. Confirm the UI slot to backend filename mapping from
   the runtime's slot-load receipt.
2. Copy the selected `.pst` and `.thumb` files into a new fixture root under
   `analysis/fixtures/sp-cache-pgo-20261031/openbios/`. Hash them and confirm
   the originals did not change.
3. Use a new PGO build directory, for example
   `build-pgo-underground-fresh`. Copy the recipe and replace only the build
   path. Keep the same source, framework, compiler and configure arguments.
4. Build and train:

   ```powershell
   python psxrecomp\tools\runtime_hot_pgo.py baseline `
     --config analysis\runtime\underground-runtime-hot-pgo-fresh.json --jobs 2
   python psxrecomp\tools\runtime_hot_pgo.py generate `
     --config analysis\runtime\underground-runtime-hot-pgo-fresh.json --jobs 2
   ```

5. Stage the rebuilt cache and overlay toolchain into the fresh PGO build
   directory. Launch the generate binary headlessly through `vr/run_vr.ps1`
   with an isolated copied save, `-WristHudTest`, HLE batching, native spans,
   PGXP, native overlays, projective stereo and 1080p/5x. Keep it running for at
   least 35 seconds, then close the owned window normally so GCC flushes all
   three `.gcda` files.
6. Confirm exactly three selected profiles are non-empty, then consume them:

   ```powershell
   python psxrecomp\tools\runtime_hot_pgo.py use `
     --config analysis\runtime\underground-runtime-hot-pgo-fresh.json --jobs 2
   ```

7. Measure control and profile-use builds in reversed order, at least two
   35-second windows per build, using identical copies and settings. Do not use
   verification/debug duplication for timing.
8. Require zero underruns, overflows, sheds, empty submissions and pair failures;
   complete stereo pairs near 60 Hz; native overlays active; and no quality
   reduction. Record guest median/minimum, work median/mean, native calls/s,
   stereo pairs, pair-time EMA, audio fill minimum/mean and every failure counter.
9. Capture one fresh side-by-side image containing both eyes, wrist HUD, weapon
   and world. Record left/right image differences.
10. Install only the accepted PGO executable into `build-release`, run a short
    normal-launcher smoke test, update this checklist and HANDOFF with the exact
    percentages and artifact hashes, then commit and push.
