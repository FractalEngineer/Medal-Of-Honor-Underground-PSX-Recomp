## Weapon tracking result

The next-mission state was not missing a calibration. It exposed three
independent guards:

- Release builds ignored synthetic XR overrides because the getter path retained
  `PSX_NO_DEBUG_TOOLS` guards.
- Silenced pistol ID 9 had the correct mesh magic, faces, nodes and topology but
  the exact SP asset hash `0xA5D4B144`, not MP's `0x65F76C5D`.
- MP40 ID 1 had the same failure after a later save update: mesh magic, 316
  faces, 32 nodes and every node count matched, but SP hash `0x431BB1CB` did
  not match MP's `0x8095CAFB`.

All three now pass through one profile rule. An exact raw hash remains accepted;
otherwise the FNV-1a over node counts plus every vertex's first six bytes
(`X/Y/Z`) must equal the calibrated MP pose hash. The final two presentation
bytes are excluded. Mesh magic, face count, node count, node counts, marker
indices and gun-only masks remain strict. This covers all 13 MP profiles and
does not require another per-save hash exception.

The diagnostics slot-2 run recorded MP40 `124/124` gun vertices per eye,
`66/66` masked arm vertices, 21 tracked profile applications and zero model
guard failures before the weapon switch. The installed production PGO build
then reached 300/300 tracked applications and 0/300 fallbacks after eight seconds
with synthetic hands and the wrist HUD. It also completed 300/300 stereo pairs
with zero XR failures. Slots 0 and 1 use P38 and pass; slot 2 also retains the
silenced pistol after switching.

The Panzerfaust now has a camera-space mount offset of `(0, -0.20, 0)` metres
(up 20 cm) in `weapon.c`. The offset is multiplied by `units_per_metre` before
being added to PSX camera coordinates. Rendering and tracked shot/laser
composition use the same offset. A physical-headset visual check remains
necessary for final height acceptance.
