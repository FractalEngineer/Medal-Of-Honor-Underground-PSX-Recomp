## Weapon tracking result

The next-mission state was not missing a calibration. It exposed two independent
guards:

- Release builds ignored synthetic XR overrides because the getter path retained
  `PSX_NO_DEBUG_TOOLS` guards.
- Silenced pistol ID 9 had the correct mesh magic, faces, nodes and topology but
  the exact SP asset hash `0xA5D4B144`, not MP's `0x65F76C5D`.

Both now pass. The corrected release run reached 210/210 weapon applications and
0/210 fallbacks in five seconds. Slot 0 and slot 1 both use P38 and also pass
with zero fallbacks. Calibrations are immutable per weapon ID and do not need to
be repeated for each mission or save.

The Panzerfaust now has a camera-space mount offset of `(0, -0.20, 0)` metres
(up 20 cm) in `weapon.c`. Rendering and tracked shot/laser composition use the
same offset. A physical-headset visual check remains necessary for final height
acceptance.
