# v0.1.5 - Full 6dof VR + Mouse/Keyboard Alpha

This patch restores mouse and keyboard control of the objective camera:

- Right mouse enters the native camera view and left mouse takes the
  photograph, using the same native-aim path as the sniper rifle.
- Walking and strafing remain available while the viewfinder is held. The
  camera keeps its native zoom and photo behavior.
- Aimed mouse sensitivity follows the camera's native depth, keeping the
  viewfinder precise.

The release retains the VR mode, configurable mouse and keyboard controls,
aimed zoom for firearms, the crossbow and both throwables, the frontend menu
input fix, mounted-gun aiming and packaged flat and VR launchers from v0.1.4.
See the
[v0.1.4 notes](https://github.com/FractalEngineer/Medal-Of-Honor-Underground-PSX-Recomp/releases/tag/v0.1.4)
for those features.

Download `mohu-0.1.5-windows-x64.zip` and extract the whole archive. Use
`RunFlat.bat` for flat play, then enable **Mouse and keyboard** in **Mods**.
Connect a headset and use `RunVR-VDXR.bat`, `RunVR-SteamVR.bat` or
`RunVR-Oculus.bat` for VR.

Supply your own **SLUS-01270 (NTSC-U)** CUE/BIN image. No game data or retail
BIOS is included. Keep your existing `saves/` folder when updating; memory-card
saves are separate from executable-specific savestates. See
[ALPHA_README.md](../../ALPHA_README.md) for setup and current limitations.

This remains a Windows alpha. Broader campaign, weapon and headset coverage
still needs playtesting.
