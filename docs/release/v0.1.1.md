# v0.1.1 - Full 6dof VR Alpha

Windows x64 alpha with the first full Underground VR gameplay path:

- **Native OpenXR stereo and head tracking:** gameplay renders independently
  for each eye while the game's videos, menus and briefing remain flat.
- **Tracked weapons and aiming:** first-person weapons follow the controllers,
  with a surface-aware right-grip laser and native recoil, ammunition and
  collision behavior preserved.
- **Wrist-mounted HUD:** native health and compass surfaces follow the left
  wrist. Under fire, the native damage marker is composited beneath the health
  ring instead of flashing the centered flat scene.
- **Objective camera and frontend:** the camera is anchored to the tracked
  wrist, and native frontend surfaces are restored outside active gameplay.
- **Sniper scope update:** weapon 5 uses a held 2.5x eye projection and the
  native final-scope range without native ADS or movement pinning. A same-zoom
  control proves the range behavior is independent of focal zoom.
- **Shared saves:** flat and VR launchers use the same `saves/` directory, so
  memory cards and compatible savestates can be carried between modes.

Download `mohu-0.1.1-windows-x64.zip`, extract the entire archive to a writable
folder, then run `RunFlat.bat` or connect an OpenXR headset and run
`RunVR-VDXR.bat`, `RunVR-SteamVR.bat` or `RunVR-Oculus.bat`.

Supply your own Medal of Honor Underground **SLUS-01270 (NTSC-U)** CUE/BIN
image. No game data or retail BIOS is included. Keep your existing `saves/`
folder when updating. See [ALPHA_README.md](../../ALPHA_README.md) for setup,
controls and remaining limitations.

This alpha remains performance-limited in demanding scenes and needs broader
physical testing of weapon impacts, sniper comfort/range and headset
transitions. Quest 3 through Virtual Desktop with VDXR is the primary accepted
setup; SteamVR and Oculus launchers are present but not broadly validated.
Windows OpenGL is the only target for this package.

The package is built from the pinned framework and committed generated game C
with the OpenXR backend and guarded VR plugin enabled. Build metadata records
the exact source revisions and executable SHA-256. This is an unsigned testing
release.
