# v0.1.7 - Linux, RecompLauncher, Achievements, VR and Mods

The big new feature is **Linux support**: the recomp now runs natively on
Linux x64 and arm64 as flat builds, with the same PGXP save flavor as Windows.
This release also brings RecompLauncher support, starter achievements, VR
launch settings and more on the game page.

## Linux x64 and arm64 are new

- Flat builds for Linux x64 and arm64, shipped as `.tar.gz` archives.
- Extract, run `./run-flat.sh`, and pick your own **SLUS-01270 (NTSC-U)**
  CUE/BIN, ISO or CHD image.
- The same `saves/` folder and PGXP save flavor move between Windows and Linux.
- Linux is flat only in this release; VR remains Windows-only. The renderer
  needs a working OpenGL 4.x driver.
- Steam Deck and other Mesa desktops use the same binary.

## Also in v0.1.7

- **RecompLauncher one-click setup**, settings on the game's page, and clear
  exit-code messages when a disc cannot start.
- **Recomp Achievements**: five starter unlocks for the USA disc, with the
  library shipping in every build (inert outside RecompLauncher).
- **VR from RecompLauncher**: choose Virtual Desktop (VDXR), SteamVR, Meta /
  Oculus or the current OpenXR runtime on the game's page. The existing
  `RunVR-*.bat` launchers still work.
- **Mouse and keyboard on the game's page**: enable it, set look and aim
  sensitivity, choose the aimed zoom and rebind the main actions there.
- **Graphics mods on the game's page**: CRT filter, scanlines and internal
  resolution.
- **Wrong disc or region**: the runtime now refuses a readable but wrong
  serial with a specific message instead of booting the wrong release.

Download `mohu-0.1.7-windows-x64.zip` for Windows (flat and VR) or
`mohu-0.1.7-linux-x64.tar.gz` / `mohu-0.1.7-linux-arm64.tar.gz` for Linux
(flat). Supply your own **SLUS-01270 (NTSC-U)** CUE/BIN, ISO or CHD image. No
game data or retail BIOS is included.

Keep your existing `saves/` folder when updating. Memory-card saves are
separate from executable-specific savestates. See
[ALPHA_README.md](../../ALPHA_README.md) for setup and current limitations.

Linux VR, a full mission-complete achievement set and broader headset coverage
still need work.
