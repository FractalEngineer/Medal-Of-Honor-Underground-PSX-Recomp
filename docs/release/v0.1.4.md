# v0.1.4 - Full 6dof VR + Mouse/Keyboard Alpha

This patch fixes mouse and keyboard input on native frontend screens and
extends aimed zoom to throwables:

- Native frontend screens, including mission-end Evaluation and
  codename/typewriter pages, now use the menu profile. Gameplay bindings no
  longer fire or navigate underneath them.
- Right-click aimed zoom, the aiming reticle and zoom-compensated sensitivity
  now work for the stick grenade and petrol bomb, matching ordinary firearms
  and the crossbow. Throw arcs and projectile origins remain native.

The release retains the VR mode, configurable mouse and keyboard controls,
aimed zoom for firearms and the crossbow, visible held weapons, mounted-gun
aiming and packaged flat and VR launchers from v0.1.3. See the
[v0.1.3 notes](https://github.com/FractalEngineer/Medal-Of-Honor-Underground-PSX-Recomp/releases/tag/v0.1.3)
for those features.

Download `mohu-0.1.4-windows-x64.zip` and extract the whole archive. Use
`RunFlat.bat` for flat play, then enable **Mouse and keyboard** in **Mods**.
Connect a headset and use `RunVR-VDXR.bat`, `RunVR-SteamVR.bat` or
`RunVR-Oculus.bat` for VR.

Supply your own **SLUS-01270 (NTSC-U)** CUE/BIN image. No game data or retail
BIOS is included. Keep your existing `saves/` folder when updating; memory-card
saves are separate from executable-specific savestates. See
[ALPHA_README.md](../../ALPHA_README.md) for setup and current limitations.

This remains a Windows alpha. Broader campaign, weapon and headset coverage
still needs playtesting.
