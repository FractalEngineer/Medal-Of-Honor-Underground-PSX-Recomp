# v0.1.2 - Full 6dof VR + Mouse/Keyboard Alpha

Adds mouse and keyboard campaign gameplay alongside the existing optional VR
mode in the Windows x64 package.

- Direct mouse aiming and WASD movement, including movement while scoped.
- Editable gameplay and menu bindings, including mouse buttons and wheel
  weapon cycling. R reloads; menu defaults are E to choose and Q to go back.
- Independent 1-10 global and aiming sensitivity sliders, defaults 5 and 4.
- Smooth aiming zoom from 1.00x to 2.50x, default 1.25x, for firearms and the
  crossbow. The held weapon stays visible and the native crosshair appears only
  while aiming. The sniper retains its native scope.
- More precise fractional mouse aiming and corrected scoped projectile origins.
- Full 6dof OpenXR VR, tracked weapons, wrist HUD and runtime launchers retained.

Download `mohu-0.1.2-windows-x64.zip` and extract the whole archive. Use
`RunFlat.bat` for flat play, then enable **Mouse and keyboard** in **Mods**.
Connect a headset and use `RunVR-VDXR.bat`, `RunVR-SteamVR.bat` or
`RunVR-Oculus.bat` for VR. The MKB feature defaults off and targets local
single-player campaign play.

Supply your own **SLUS-01270 (NTSC-U)** CUE/BIN image. No game data or retail
BIOS is included. Keep your existing `saves/` folder when updating; memory-card
saves are separate from executable-specific savestates. See
[ALPHA_README.md](../../ALPHA_README.md) for setup and remaining VR limitations.

This remains an unsigned Windows alpha. VR performance, broader weapon/mission
coverage and headset/runtime compatibility need further playtesting. Quest 3
with Virtual Desktop VDXR remains the primary tested VR setup.
