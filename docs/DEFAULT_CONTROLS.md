# Medal of Honor Underground — Default Controls

Reference for the game's built-in **Config. 2** control layout.

![Default controls (Config. 2)](default-controls.png)

> Drop the original control-card image at `docs/default-controls.png` for it to
> render here.

## Menus

| Button | Action |
| --- | --- |
| Square | Browse |
| Cross (X) | Choose |
| Triangle | Go back |

## Movement

| Input | Action |
| --- | --- |
| Left stick / D-pad up | Forward |
| Left stick / D-pad down | Back |
| Left stick / D-pad left | Turn |
| Left stick / D-pad right | Turn |
| L3 (press in) | Center view |
| Right stick | Strafe / Look |

## Face buttons

| Button | Action |
| --- | --- |
| Triangle | Jump |
| Square | Reload / Action |
| Circle | Change weapon |
| Cross (X) | Fire |

## Shoulder buttons

| Button | Action |
| --- | --- |
| L1 | Strafe left |
| L2 | Crawl |
| R1 | Strafe right |
| R2 | Aim / Look |

## System

| Button | Action |
| --- | --- |
| Start | Pause |
